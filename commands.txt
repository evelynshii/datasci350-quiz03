Task 2

I created `ollama/Modelfile` using `granite4:350m` as the base model. I set the temperature to 0.8 to allow more expressive responses and added `num_predict 150` to limit the maximum number of generated tokens. The SYSTEM instructions give the model an enthusiastic live sports commentator persona and specify three rules: every answer must contain no more than four sentences, the model must address the user as "sports fans", and it must openly acknowledge when it does not know an answer rather than inventing information.

Task 3
cd ~/datasci350-quiz03
ollama create commentator -f ollama/Modelfile
ollama ls

The `ollama create` command builds a custom model named `commentator` using the instructions in `ollama/Modelfile`. This command download nothing because `granite4:350m` is already stored locally. Ollama can reuse the existing model weights while applying the new parameters and system instructions.
